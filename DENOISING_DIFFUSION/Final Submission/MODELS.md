# Trained models and how to retrain them

The final model averages four U-Net checkpoints. Each network learns a correction on top of a 3D Wiener filter (`--arm wiener`), with a spectral context of K = 15 channels (plus and minus 1.5 km/s at 0.1 km/s per channel).

| file | how it was trained | evaluation of the run |
|---|---|---|
| `unified_r4n_k15_long.pth` | 80 rounds (24,000 steps), learning rate 1.5e-4, seed 3 | [`results/10-training-runs/r4n-k15-long_v1_2026-10-12/`](results/10-training-runs/r4n-k15-long_v1_2026-10-12/) |
| `unified_r4n_k15_long_s11.pth` | the same, seed 11 | [`results/10-training-runs/r4n-k15-long-s11_v1_2026-10-13/`](results/10-training-runs/r4n-k15-long-s11_v1_2026-10-13/) |
| `unified_r4n_k15_long_s23.pth` | the same, seed 23 | [`results/10-training-runs/r4n-k15-long-s23_v1_2026-10-13/`](results/10-training-runs/r4n-k15-long-s23_v1_2026-10-13/) |
| `unified_r8_m1_r6.pth` | 80 rounds on 256 px crops (batch 4, seed 31), then 20 rounds of fine-tuning with a line-centre (M1) penalty of weight 0.01 (learning rate 5e-5, seed 51) | [`results/10-training-runs/r8-m1-r6_v1_2026-10-15/`](results/10-training-runs/r8-m1-r6_v1_2026-10-15/) |

Inference settings (gate `40,120,0.25`, second Wiener pass, size normalisation to a 10 px beam) are the defaults of `experiments/alma_unified.py`; see [`results/final/RECIPES.md`](results/final/RECIPES.md).

Checkpoint format: a PyTorch dictionary holding the weights (`model_state_dict`) and the settings needed to rebuild the network (`K`, `arm`, `base`, `base_channels`, `channel_multipliers`, `in_channels`, `out_channels`, `args`). Networks 1 and 2 are about 116 MB. Networks 3 and 4 are about 349 MB because they also store the optimiser, scheduler and random-number state used to resume training across Kaggle sessions; inference ignores those.

## Availability

The weights are not in this repository. They were trained on synthetic disks that are not public, and will be released when that is permitted.

## Reproducing the final model

The commands below trained the four networks and produced the main evaluations. The Kaggle scripts that ran them are in [`kernels/`](kernels/) as they ran; these are the same calls without the Kaggle-specific setup.
### Data

| input | used for | source | in this repository |
|---|---|---|---|
| line-emission cubes (14 cubes, about 7.6 GB) | training and held-out evaluation | synthetic (hydrodynamics plus radiative transfer), not public | no |
| self-gravitating hydro disks (`sg_synth`) | training; disk 9074 held out | built by `experiments/synthesize_sg_pairs.py` from the self-gravitating clean cubes and the recovered beam | no (the inputs are not public) |
| second self-gravitating cube (`kinematic_data_v2`) | evaluation | synthetic, not public | no |
| analytic GI disks (an01 to an16, twins) | training (an01 to an06) and testing | generated by `experiments/make_analytic_gi_cubes.py`, no input data | generated |
| Young et al. (2026) simulations | testing only | rendered by `experiments/make_sph_cubes.py` from the simulation snapshots | no |
| Speedie et al. (2024) disk and twin | testing only | prepared by `experiments/speedie_prep.py` | no |
| exoALMA and DSHARP cubes | real-data evaluation only, never trained on | public archives (exoALMA I, DSHARP) | no |

Expected layout, relative to this folder (or set `EXXA_ROOT`): `Line Emission Data/run_*` (or set `LE_DIR`), `self-gravitating cube and dirty cube/sg_synth/` and `self-gravitating cube and dirty cube/kinematic_data_v2/`.

### Environment

Python 3.10 or newer, `pip install -r requirements.txt` (numpy 2 is required). One GPU with about 16 GB; each 80-round training run takes about 11 hours on a Kaggle P100. Every run saves its full state after each round, and `--resume <checkpoint>` continues an interrupted run from where it stopped.

### Training the four networks

Common flags (all four):

```bash
COMMON="--arm wiener --k 15 --snr 3,150 --chan-corr 0.5 --beam-max 1.6 --clip-in 10 --fp32-stream --norm robust --eval-ladder 3,6,12,24"
python experiments/make_analytic_gi_cubes.py                     # the analytic training and test disks
```

```bash
# networks 1 to 3: the same recipe, three seeds (80 rounds = 24,000 steps)
python experiments/train_unified.py $COMMON --lr 1.5e-4 --rounds 80 --seed 3  --tag r4n_k15_long     --out runs/seed3
python experiments/train_unified.py $COMMON --lr 1.5e-4 --rounds 80 --seed 11 --tag r4n_k15_long_s11 --out runs/seed11
python experiments/train_unified.py $COMMON --lr 1.5e-4 --rounds 80 --seed 23 --tag r4n_k15_long_s23 --out runs/seed23

# network 4, stage 1: 256 px training crops, batch 4
python experiments/train_unified.py $COMMON --lr 1.5e-4 --rounds 80 --crop 256 --batch 4 --seed 31 --tag r6_k15_crop256 --out runs/crop256
# network 4, stage 2: fine-tune with the line-centre (M1) penalty, warm-started from stage 1
python experiments/train_unified.py $COMMON --lr 5e-5 --rounds 20 --w-m1 0.01 --m1-crops 2 --m1-crop 96 --crop 256 --batch 4 --seed 51 \
    --warm runs/crop256/unified_r6_k15_crop256.pth --tag r8_m1_r6 --out runs/m1
```

Add `--sph-dir <young renders>` and `--speedie-dir <speedie cubes> --eval-speedie GI_r0.5,Kep_r0.5,GI_r1.5,Kep_r1.5` to score the held-out simulations after training, as the original runs did. Each run writes its checkpoint and an evaluation JSON; the evaluation files of the original runs are in [`results/10-training-runs/`](results/10-training-runs/).

### Evaluating the final model

The final model averages the four checkpoints, with the do-no-harm gate, the second Wiener pass and the size normalisation:

```bash
CKPTS=runs/seed3/unified_r4n_k15_long.pth,runs/seed11/unified_r4n_k15_long_s11.pth,runs/seed23/unified_r4n_k15_long_s23.pth,runs/m1/unified_r8_m1_r6.pth
INFER="--gate 40,120,0.25 --wiener2 --infer-beam-px 10 --infer-mode full"

# the one-time final test (Speedie r1.5 at SNR 6, 12, 24); see results/01-final-test/
python experiments/train_unified.py --eval-only --eval-ckpt $CKPTS $INFER --n-line-eval -1 --eval-sg "" --sizes 600 \
    --speedie-dir <speedie cubes> --eval-speedie "" --eval-ladder 6,12,24 --ladder-base GI_r1.5,Kep_r1.5 --tag final_test_B --out runs/final_test
```

The five-size evaluation, the fresh test set and the real-data runs use the same model; their exact arguments are in `kernels/eval_five_sizes.py`, `kernels/eval_fresh_set.py`, `kernels/alma_exoalma.py` and `kernels/alma_dsharp.py`. For a single cube, new or published, see [`USAGE.md`](USAGE.md).

### What has and has not been re-run

The commands above are taken from the scripts that produced the published numbers. They were not re-run for this submission: a full reproduction needs the non-public training disks and about five GPU runs of 6 to 11 hours each. The evidence of the original runs is the evaluation files under [`results/`](results/).
